# Face to Face

Раунды быстрых знакомств: случайные пары на 5 минут, при нечётном числе одна тройка, повторов как можно меньше.
Организатор ведёт мероприятие с одного ноутбука или проектора, участники находят свою группу по номеру с телефона.

## Деплой на Vercel

1. Залейте папку в GitHub-репозиторий и импортируйте его в Vercel (Framework Preset: **Other**, сборка не нужна).
2. В проекте откройте **Storage → Create Database → Upstash for Redis** (бесплатный план) и подключите его к проекту.
   Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
3. Сделайте Redeploy.

Без базы сайт тоже работает, но данные хранятся только в браузере организатора, и ссылка для участников не откроется.

## Как устроено

- `index.html`, `app.js`: интерфейс организатора и страница участника (`?e=<id>`).
- `core.js`: подбор пар без повторов и разбор списка участников.
- `api/event.js`: `GET`/`PUT` одного мероприятия в Redis. Писать можно только с ключом организатора,
  который создаётся в браузере вместе с мероприятием. Без ключа API отдаёт только номера, без имён.
- Мероприятие дублируется в `localStorage`, поэтому интернет может пропасть посреди раунда: всё
  отправится в облако при следующем сохранении.
